Free View

Drag to orbit; W / S forward/backward, A / D left/right, Q / E to move vertically; scroll to move forward or backward. Click the canvas before using the keyboard.

Anti-flicker adds GPU overhead; fast-moving edges may soften slightly. Pausing restores single sampling.

Display frame rate is limited by monitor refresh rate, network, and GPU limits. Target frame rate does not reduce image quality. Live preview uses a bounded buffer; fully preloaded sequences play locally.

While moving, single sampling improves responsiveness. Anti-flicker resumes when still. Disable adaptive preview to keep the selected resolution; model precision is unchanged.

Once preloaded, the current view plays without per-frame network transfers. Moving the camera triggers new rendering. Memory-only cache, up to 96 MiB image data.

Orbit Video

The overview path completes a full orbit at a fixed distance, with elevation varying only between 1°–3°with smooth acceleration and the whole object in frame. The short-arc path starts from Lego the original front view, slowly rotating 3°、raise 0.5°before returning at a fixed distance and framing, without moving behind the object. Full orbit uses the current camera, target distance, and elevation range, and may reveal incomplete reconstruction. Animation continues; the video excludes UI text.

Export uses GPU, may temporarily reduce the browsing frame rate. MP4 includes a parameter summary; JSON stores each frame's full trajectory separately. Per-export limit: 256 MiB, Total export budget 1 GiB; Server copies can be deleted after downloading.
